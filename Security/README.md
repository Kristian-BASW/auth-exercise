# Auth exercise

1. Create interface `IAuthorizationService` with a method called `GenerateToken`
2. Implement the interface
3. Check that you can generate the token, when logging in.
4. Try to make use of the `Authorize` for an endpoint
5. Implement so all of the endpoints can use the authorization.
6. Create a new endpoint for getting all users where the user needed to be authorized
7. Implement the authorization for swagger.
8. Try to implement some specific roles for the authorization.
